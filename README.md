# 餘裕 — 生活設計管理 App

個人餘裕管理工具：記錄煩惱與心願、每週規劃預測負擔曲線、餘裕超過 20% 時建議如何使用、追蹤長期投資（閱讀／運動／冥想）的累積成長。手機、電腦都能用同一個網址，資料存在 Render 的 PostgreSQL 裡。

## 功能對照（v2）

- **事件（負擔）**：三種大類，各自附日期
  - 急性情緒（淡化型）：快（隔天）／中（3 天）／長（7 天）三種速度，用點量表呈現，過期自動刪除
  - 慢性壓力（進度型）：10 點量表，直接點選第幾點設定完成度，滿 10 點自動結案
  - 待辦清單（單次型）：固定負擔，手動標記已解決
- **完成清單**（獨立列表）：功課／工作／身體健康／心理照顧／自我成長／家務財務六個分類，選擇「輕盈程度」決定餘裕加成幅度，並各自對應到一條成長軸線
- **隨手記**：低摩擦捕捉腦中雜念，未整理的想法仍會佔一點點分數，提醒你找時間整理
- **每週規劃**：只記可預期的事，分課業／工作／聚會／出遊四類，用日期選擇器點選日期，本週負擔以長條圖呈現（長條越高負擔越重）
- **餘裕儀表板**：置中呼吸圓環顯示當下餘裕％、14 天趨勢圖、負擔來源分類、六軸長期成長（合併呈現在此頁）

### 六軸成長對照表

| 完成清單分類 | 對應成長軸 |
|---|---|
| 功課 | 專業技能力 |

| 身體健康 | 體力 |
| 心理照顧 | 精神穩定度 |

### 想調整數值時去哪裡改

所有跟「餘裕/成長」有關、你會想手動調整的基本數值，都集中放在 `server.js` 檔案最上面的「🎛️ 數值控制台」區塊，直接改數字存檔重新部署即可：

- `LIGHTNESS_MAP`：完成清單裡「小輕鬆/滿輕鬆/非常輕鬆」三個等級，各自帶來多少餘裕加成
- `GROWTH_AMOUNT_PER_COMPLETION`：每記錄一次完成清單，六條成長軸各自要累加多少分數（目前固定 +1，不分輕盈程度）
- 淡化速度的天數／衰退曲線：在 `lib/calc.js` 檔案最上面的 `ACUTE_DOTS`、`EFFORT_K`、`NOTE_BURDEN_PER_ITEM`、`NOTE_BURDEN_CAP`

改完這些常數後，`git push` 讓 Render 重新部署即可生效，不需要動到資料庫。

## 升級舊部署

如果你先前已經部署過 v1 版本，這次的 `db/schema.sql` 用 `ALTER TABLE ... ADD COLUMN IF NOT EXISTS` 補上新欄位，直接重新部署（push 新程式碼到 GitHub，Render 會自動重新建置）即可升級，既有資料不會被清空。

## 部署到 Render（一次性設定）

1. 把這個資料夾推到你自己的 GitHub repo（新建一個 repo，`git init && git add . && git commit -m "init" && git push`）。
2. 登入 [Render](https://render.com) → 右上角 **New** → **Blueprint**。
3. 選擇你剛剛的 GitHub repo，Render 會讀取專案裡的 `render.yaml`，自動建立：
   - 一個 **Web Service**（跑 Node.js，`npm install` → `npm start`）
   - 一個 **PostgreSQL 資料庫**，並自動把連線字串填進 Web Service 的 `DATABASE_URL` 環境變數
4. 按下部署。伺服器啟動時會自動讀取 `db/schema.sql` 建表（用的是 `CREATE TABLE IF NOT EXISTS`，重複部署也安全），並自動塞入預設的活動建議清單。
5. 部署完成後，Render 會給你一個網址，例如 `https://margin-app-xxxx.onrender.com`，手機、電腦都用這個網址打開即可，記得加進手機主畫面方便使用。

免費方案的 Web Service 閒置一段時間會休眠，重新打開時第一次讀取會慢個幾秒，之後就正常。若想避免這個延遲，可以在 Render 把方案升級。

## 本機開發（選用）

若你想先在自己電腦跑起來測試：

```bash
npm install
export DATABASE_URL=postgres://使用者:密碼@localhost:5432/margin_app
npm start
```

打開 `http://localhost:3000` 即可。

## 之後想擴充時的入口

- 決定衰減公式的地方：`lib/calc.js`（`DECAY_K` 常數、`computeEventBurden`）
- 每週預測曲線邏輯：`lib/calc.js` 的 `computePredictedWeek`
- 活動建議清單：`lib/seed.js`
- 若要加自動化週期事件（例如「每週固定的諮商」自動生成），可以在 `events` 表的 `is_recurring` / `recurrence_rule` 欄位上加一支排程腳本，目前這版先讓你手動在每週規劃裡加入。
